Chest-xray-pneumonia-detection
Problem Statement

Pneumonia is a serious lung infection that affects millions of people worldwide.Manual diagnosis from chest X-rays requires expert radiologists and can be time-consuming. This project explores the use of deep learning models for automated pneumonia classification from chest X-ray images.
Dataset
